🎯 坐標系統說明

🔵 TWD97 (藍色圓形)

  • 台灣官方測量基準
  • 政府機構標準
  • 1997年1月1日起實施
  • 與WGS84相差僅公分級
  • 適用於台灣地區製圖

🔺 WGS84 (紅色三角形)

  • GPS標準坐標系統
  • 全球定位參考系統
  • 大多數GPS設備使用
  • 國際通用標準
  • 全球性坐標基準

🔍 主要發現

  • 系統性偏移：兩種坐標系統間存在約850公尺的系統性偏移
  • 高度一致性：標準差僅13公尺，顯示偏移量相當一致
  • 非隨機誤差：偏移量呈現規律性，非隨機分佈
  • 全台適用：所有336個測站都顯示類似的偏移模式
  • 實務意義：在台灣地區使用坐標時需注意坐標系統的選擇

🔬 技術方法

資料來源：中央氣象署開放資料平台 API (O-A0003-001)

分析方法：

  • 獲取每個氣象站的兩組坐標資料
  • 將兩組坐標都視為WGS84 EPSG:4326進行比較
  • 使用Geopy計算兩點間的大圓距離
  • 使用Cartopy繪製真實台灣地圖背景
  • 進行統計分析計算各項指標

📝 結論

本研究確認了TWD97與WGS84坐標系統在台灣地區存在約850公尺的系統性偏移。這個發現對於：

  • GIS系統開發者：需注意坐標系統轉換
  • 測量工程師：應選擇適當的坐標基準
  • 導航應用開發：需考慮坐標系統差異
  • 學術研究：提供坐標系統比較的實證資料
